Right-click a 3D file. Pick a format. Done.

convert3d adds Convert 3D to and Preview 3D to the right-click menu of your 3D files. Choose glTF, FBX, USD or any other format, and the converted file appears next to the original.

Download

Download for WindowsConvert3D-Setup.exe · Windows 10 and 11
  1. Run the downloaded file. No administrator rights are needed.
  2. Leave "install Blender" ticked if it is offered. Blender is the engine that does the work.
  3. Right-click a 3D file and choose Convert 3D to or Preview 3D. On Windows 11 they are under Show more options (or hold Shift while right-clicking).

Windows may say "Windows protected your PC" because the installer is not code-signed. Click More info, then Run anyway.

Download for macOSConvert3D-macOS.pkg · Intel and Apple Silicon
  1. Install Blender, the engine that does the work (or brew install --cask blender).
  2. Open the downloaded file. macOS will warn that it is not from an identified developer: go to System Settings > Privacy & Security and click Open Anyway (on older versions: right-click the file and choose Open).
  3. Right-click a 3D file in Finder and choose Quick Actions > Convert 3D… or Preview 3D.

If the Quick Actions do not show up, turn them on in System Settings > General > Login Items & Extensions > Finder.

Prefer the Terminal? This installs it for your user only, with no warning to click through:

curl -fsSL https://raw.githubusercontent.com/srlegrand/convert3d/main/install.sh | sh
Download for LinuxConvert3D-x86_64.AppImage · Dolphin, GNOME Files
  1. Install Blender, the engine that does the work, for example sudo snap install blender --classic.
  2. Make the downloaded file executable (Properties > Permissions, or chmod +x), double-click it and click Install.
  3. Close all file manager windows and open them again. Then right-click a 3D file and choose Convert 3D to or Preview 3D (in GNOME Files they are under Scripts).

ARM computers, or no AppImage please:

curl -fsSL https://raw.githubusercontent.com/srlegrand/convert3d/main/install.sh | sh

What it does

Converts between 3D formats

FBX, glTF, OBJ, USD, Alembic, Blender, STL, PLY and more, in any direction. Select several files to convert them all.

Previews in your browser

Orbit, pan and zoom the model, play its animations, and see triangle, material and texture counts. Works offline.

Understands zips

Right-click a zip with a model and its textures. Broken texture paths are repaired by finding the files inside the zip.

Uses the apps you have

Blender does most of the work. Assimp, Maya, 3ds Max and Aztek add their formats when they are installed.

Good to know

What happens to my original file?

Nothing. convert3d writes a new file next to it, such as chair.glb. If that name is taken it asks, or writes chair_(2).glb. Where output goes

Is my model sent anywhere?

No. Everything runs on your own computer using Blender and the other tools you have installed. There is no account, no tracking and no internet connection involved. Previews open in your browser, but from a file on your disk.

Why does my computer warn me about the installer?

Signing certificates from Microsoft and Apple cost money every year, and this is a free project. The installers are built automatically by GitHub from the public source code.

A format is missing from the menu

The menu lists what the tools found on your computer can write. After installing Assimp, Maya or 3ds Max, install convert3d again (or run convert3d install) to add their formats. More in the docs

How do I remove it?

Windows: Settings > Apps > Installed apps > Convert 3D > Uninstall.
macOS: run convert3d uninstall in Terminal.
Linux: double-click the AppImage again and choose Remove, or run convert3d uninstall.
