Using it

Right-click one or more 3D files, or a zip with a model and its textures.

SystemWhere the entries are
WindowsConvert 3D to and Preview 3D. On Windows 11 under Show more options, or hold Shift while right-clicking.
macOSQuick Actions > Convert 3D…, which then asks for the format, and Quick Actions > Preview 3D.
Linux, KDE DolphinConvert 3D to and Preview 3D.
Linux, GNOME FilesScripts > Convert 3D to and Scripts > Preview 3D.

A notification says when a conversion starts and when it is done. If it fails, a dialog shows the end of the log.

Formats and tools

convert3d does not convert anything itself. It drives the 3D applications on your computer, and chains them when one cannot do the whole job: a .dae becomes a .usdz through Assimp and then Blender.

FormatsNeeds
fbx, glb, gltf, obj, abc, usd, usda, usdc, usdz, blend, stl, plyBlender 4.2 or newer
dae, 3ds, x, 3mf, x3d, and about 35 read-only formats (lwo, ase, ms3d, md2, md3, ifc, off, smd...)Assimp
ma, mbMaya or Aztek
max3ds Max (Windows only)

Blender is required. The rest is optional.

After installing a new tool

The menu lists the formats that the tools found at install time can write. After adding Assimp, Maya or 3ds Max, refresh it:

convert3d install

See which tools were found:

convert3d doctor

If a tool is somewhere unusual, such as a Flatpak or a portable Blender, point convert3d at it:

convert3d set-tool blender "/path/to/blender"
convert3d set-tool assimp  "/path/to/assimp"
convert3d set-tool mayapy  "/path/to/mayapy"
convert3d set-tool 3dsmax  "C:\Program Files\Autodesk\3ds Max 2026\3dsmaxbatch.exe"

Where output goes

  • chair.fbx becomes chair.glb, in the same folder.
  • Formats with separate texture files (obj, gltf, usda, dae...) go into a folder: chair_obj/.
  • If the input was a zip, results with several files are zipped again: chair_obj.zip.
  • When the name is taken, convert3d asks whether to overwrite it or keep both. Keeping both writes chair_(2).glb, then chair_(3).glb.

The original is never modified.

Options

Open Options at the bottom of the Convert 3D to menu (on macOS: Quick Actions > Convert 3D Options), or run convert3d options.

  • Output folder. Save next to the original, or ask for a folder before each conversion.
  • Existing files. Ask, always overwrite, or always keep both by adding a number to the name.
  • Application per format. Choose which application reads and which writes each format, for example Maya instead of Blender for FBX. You can also pick any other program that accepts program input output.

Changes apply to the next conversion.

Previews

Preview 3D opens the model in your web browser. Drag to orbit, right-drag to pan, scroll to zoom. The page shows triangle, material and texture counts and the model's size, plays animations, and has wireframe, grid and background toggles.

A .glb opens at once. Other formats are converted with Blender first, which takes a few seconds. The page is a single file that works offline, and the last 20 are kept in convert3d's cache folder.

Thumbnails

On Linux, installing also adds a thumbnailer, so the file manager shows the model as the file's icon. It works in KDE Plasma 6 Dolphin, Thunar, Nemo and Caja. Each thumbnail is rendered by Blender and takes a couple of seconds the first time.

  • KDE Plasma 5 and GNOME Files do not show them.
  • In Dolphin, turn previews on, and check that the size limit in Settings > Interface > Previews is not below the size of your models.
  • On macOS and Windows convert3d adds no thumbnails. Finder's Quick Look (space bar) already previews usdz, usd, obj, stl, ply and abc.

Zips

Model packs often come as a zip with a model and a folder of textures. Right-click the zip itself: convert3d looks inside for the model (FBX first, then glTF, USD, Alembic, OBJ...) and converts it.

Texture paths that point somewhere that no longer exists, such as C:\Users\someone\textures\wood.png, are repaired by finding a file with the same name in the zip.

Command line

convert3d convert --to glb chair.fbx table.obj props.zip
convert3d convert --to usdz --out-dir ./usd *.fbx
convert3d view chair.fbx                 # open a preview in the browser
convert3d thumbnail --size 512 chair.fbx chair.png
convert3d formats                        # every format, and whether it works here
convert3d doctor                         # tools found, settings, log folder

Where the command is after installing:

Windows%LOCALAPPDATA%\convert3d\bin\convert3d.exe
macOSconvert3d (installer package), or ~/Library/Application Support/convert3d/bin/convert3d
Linuxconvert3d, linked in ~/.local/bin

To build it yourself you need Rust:

cargo install --git https://github.com/srlegrand/convert3d
convert3d install

Uninstall

WindowsSettings > Apps > Installed apps > Convert 3D > Uninstall
macOSconvert3d uninstall, then sudo rm /usr/local/bin/convert3d if you used the installer package
LinuxDouble-click the AppImage again and choose Remove, or run convert3d uninstall

This removes the menus, the thumbnailer and convert3d's copy of itself. Blender and the other tools are left alone.

Troubleshooting

The menu does not appear

Linux: close every file manager window and open it again.
macOS: turn the Quick Actions on in System Settings > General > Login Items & Extensions > Finder.
Windows 11: look under Show more options.

"Blender was not found"

Install Blender, or tell convert3d where it is with convert3d set-tool blender /path/to/blender. A Flatpak Blender is not found automatically.

A conversion failed

The error dialog shows the end of the log. Full logs are in the folder that convert3d doctor prints. Please attach the log when you report a problem.

Textures are missing after converting

Alembic, STL and PLY cannot hold materials, so textures are dropped when converting to them. For other formats, keep the textures next to the model or convert the zip they came in, so convert3d can find them.

.max, .ma or .mb will not convert

.max needs 3ds Max, which only exists for Windows. .ma and .mb need Maya or Aztek.
